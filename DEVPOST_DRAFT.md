## Tagline (one line)

## Elevator pitch (short, for the submission summary field)
Sporewick is a cozy mobile idle game: plant glowing spores in garden
plots, let them grow, harvest them, and combine pairs at a crossbreeding
altar (the Wick) to discover new hybrid mushroom species for your
compendium. Ten discoverable species so far — three base spores, three
cross-type hybrids, and three "refined" same-type variants — with more
planned. Built in Godot 4, with RevenueCat powering a one-off spore pack
and a growth-boosting subscription.

## What it does
- Plant one of three base spore types (Ember Cap, Moss Puff, Glimmer
  Truffle) in a garden plot.
- Wait for it to grow (currently a 60-second real-time cycle), or come
  back later — growth continues while the app is closed and catches up
  on relaunch, so nothing is lost by not watching a timer.
- Harvest ready spores into inventory, earning currency.
- Combine two harvested spores at the Wick: matching cross-type pairs
  discover one of three hybrid species; pairs of the *same* type discover
  a "refined" variant instead — ten discoverable species total, tracked
  in a compendium.
- Spend real currency in two IAPs (via RevenueCat): a one-off Spore Pack
  for an instant 3 spores, or a Wick's Blessing subscription that halves
  growth time while active.

## How we built it
- **Engine:** Godot 4.3 (GDScript), chosen for fast iteration and clean
  mobile export.
- **Monetization:** RevenueCat, via the community `godot-x/revenuecat`
  plugin, wrapped in a small `PurchaseManager` autoload exposing
  `initialize()`, `fetch_offerings()`, `purchase_package()`,
  `has_entitlement()`, and `restore_purchases()`.
- **Art:** all spore icons and the app icon are original, hand-authored
  SVGs generated by a small parameterized Python tool
  (`tools/gen_spore_icons.py` / `tools/gen_app_icon.py`) rather than
  stock assets — every asset's license is logged in `ASSET_LOG.md`.
- **Testing:** a from-scratch headless verification tool
  (`tools/run_headless_verify.sh`) runs the real game logic end to end
  under Godot's `--headless` mode with software OpenGL rendering
  (Xvfb + llvmpipe), asserting on real game state and capturing genuine
  rendered screenshots at each step — not mocked, not just "trust me it
  works." The suite has grown to 35 passing assertions covering the core
  loop, same-type combos, save/load with offline-progress catch-up, a
  perf sanity check, and both IAP flows.

## Challenges we ran into
- **Offline progress without a backend:** getting a plot that finished
  growing while the app was closed to catch up correctly on relaunch,
  without a server — solved with a `saved_at` timestamp in the local save
  file and an elapsed-time catch-up pass on load.
- **Headless rendering pitfalls:** two separate bugs where the
  verification tooling looked like it was working but wasn't — a
  relative-path bug that silently wrote screenshots to the wrong nested
  directory, and Godot's imported-texture cache not existing on a fresh
  checkout, which would have hidden real rendering regressions behind
  passing gameplay-logic assertions. Both are documented and fixed in
  `STATE.md`'s changelog.
- **Same-type spore combos:** deciding what should happen when you
  combine two spores of the same base type — landed on a dedicated
  "refined" result rather than a generic fallback, so it reads as a
  deliberate alternate strategy instead of an edge case.

## Accomplishments we're proud of
